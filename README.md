Hi, I'm Nurettin. I build products, one commit at a time — currently at Virta, in Finland. Lately that means helping AI coding agents build the *right* thing, not just build things fast.

### What I'm building

**[ai-prd-workflow](https://github.com/nurettincoban/ai-prd-workflow)** &nbsp; [![GitHub stars](https://img.shields.io/github/stars/nurettincoban/ai-prd-workflow?style=social)](https://github.com/nurettincoban/ai-prd-workflow/stargazers)<br />
RFC-driven development for AI coding agents. An idea, or a codebase that already exists, becomes a verified PRD, prioritized features, project rules and small RFCs in dependency order — then gets implemented and reviewed one RFC at a time. It ships as a Claude Code plugin and as Agent Skills for Codex, Copilot, Cursor, Gemini CLI, OpenCode and Devin, and is supported by Anthropic through its open source program.

**[diff2ai](https://github.com/nurettincoban/diff2ai)** &nbsp; [![npm](https://img.shields.io/npm/v/diff2ai.svg?logo=npm&label=npm)](https://www.npmjs.com/package/diff2ai)<br />
Turns your Git diffs into high-signal AI code review prompts — fast, local, and repo-safe.
